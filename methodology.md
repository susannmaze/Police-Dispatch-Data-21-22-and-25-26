# Methodology

The 2021–22 export was standardized to the 2025–26 schema.

## Field mapping
- `ExtNatureDisplayName` -> `Call Type`
- `PolArea` -> `Dispatch Police Beat / Area`
- `Address` -> normalized uppercase address for crosswalk matching

## Geography
The current master address crosswalk was used for both periods. Police beat was not used to infer Ward or Precinct.

2021–22 crosswalk match rate: 15,385/89,262 (17.2%).

## Period normalization
Annualized rate = calls / days covered x 365.
